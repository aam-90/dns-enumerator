# DNS Enumerator

A simple Python DNS enumeration and analysis tool built with dnspython.

## Features

- A record lookup
- AAAA record lookup
- NS record lookup
- CNAME record lookup
- MX record lookup
- PTR record lookup
- SOA record lookup
- TXT record lookup
- TTL information
- Reverse DNS lookup
- Command-line options
- JSON output
- DNS timeout and error handling

## Requirements

- Python 3
- dnspython
