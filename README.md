# DNS Enumerator

A Python-based DNS enumeration and analysis tool built with
[dnspython](https://www.dnspython.org/).

## Features

- Query common DNS record types
- Display record TTL values
- Reverse DNS lookups
- Configurable DNS resolver
- JSON output
- Input validation
- DNS error handling
- Unit tests
- Logging
